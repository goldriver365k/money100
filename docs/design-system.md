# 생활계산서 디자인 시스템 (다른 웹에 옮겨 쓰기)

바로 쓰는 CSS: [`docs/design-starter.css`](design-starter.css) — 아래 내용을 코드로 옮긴 최소 세트.

## 1. 성격
- **도구형(Operate) 화면**: 꾸밈보다 "빨리 찾고, 정확히 입력하고, 결과를 믿게" 하는 것이 목표.
- **신뢰 중심**: 적용 기준·확인일·출처를 결과 옆에 표시, 입력값은 저장·전송하지 않는다고 분명히 안내.
- **차분한 바탕 + 분야 색 한 가지 포인트**: 흰 카드·옅은 청회색 바탕 위에 분야별 색을 아이콘·라벨·버튼에만.

## 2. 색
| 역할 | 밝은 모드 | 다크 모드 | 쓰는 곳 |
|---|---|---|---|
| 바탕 `--bg` | #F7F9FD | #0E1430 | 페이지 |
| 카드 `--surface` | #FFFFFF | #161F46 | 카드·입력·메뉴 |
| 글자 `--text` | #1E2A5A (짙은 남색) | #E7EBF7 | 제목·본문 (순수 검정 대신) |
| 보조 `--muted` | #56608A | #AAB3D1 | 설명·힌트 (대비 6:1 이상) |
| 테두리 `--border` | #E2E7F2 | #2B376A | 카드·입력 |
| 주 색 `--brand` | #2563E2 | #7AA5FF | 주 버튼·링크·결과 숫자 |
| 연한 주 색 `--brand-soft` | #EAF1FD | #1D2B5C | 강조 바탕·안내 상자 |
| 바닥글 `--navy` | #172149 | #0A0F26 | 푸터 |

**분야 색** (글자 / 옅은 바탕 / 테두리) — 옅은 바탕 위 작은 글자 대비 4.5:1 이상으로 맞춘 값
- 파랑 #1554D6 / #E3EEFF / #B9D0FB (다크 #8FB4FF / #1B2A57)
- 보라 #6728CD / #F0E8FF / #D6C2F7 (다크 #C4A6FF / #2A1F55)
- 초록 #007A4B / #E1F9EF / #A9E6CC (다크 #5FD6A6 / #10352B) — 원래 #008B55 는 대비 3.94:1이라 보정

**규칙**
- 카드는 흰 바탕, 색은 아이콘 타일·분야 라벨·버튼·마우스 올림 테두리에만.
- 선택 상태(필터 칩)는 분야 색으로 **채움** + 흰 글자.
- 오류 #C02A1E(바탕 #FDECEA), 경고 띠 #FFF6E0 / 테두리 #E9C46A / 글자 #5B4300.

## 3. 글꼴·글자
- **Pretendard Variable** (무료, SIL OFL) — 동적 서브셋을 자체 호스팅(필요한 글자만 내려받음).
- 본문 16px / 줄 간격 1.6, **`word-break: keep-all`**(한글 낱말 단위 줄바꿈).
- 제목: 굵기 900, 자간 -0.02~-0.04em, 크기는 `clamp()`로 화면에 따라.
  - h1 `clamp(1.9rem, 6vw, 3rem)` · h2 `clamp(1.3rem, 3.4vw, 1.6rem)` · 카드 제목 1.08rem/800
- 숫자: `font-variant-numeric: tabular-nums` (자릿수 정렬).
- 결과 핵심 숫자: `clamp(2rem, 8vw, 2.6rem)`, 굵기 900 — 본문의 2배 이상.

## 4. 형태·간격
- 모서리: 카드 14px, 입력·작은 버튼 10px, 칩·필 버튼 999px, 큰 결과 상자 16px.
- 그림자: 아주 옅게 `0 6px 24px rgb(30 42 90 / .07)`, 다크 모드는 없음.
- 폭: 입력·읽기 화면 760px, 목록·홈 1160px, 좌우 여백 16px.
- 화면 구간: 480 · 600 · 720 · 900 · 1024px (900px 이상에서 왼쪽 사이드바 표시).
- **누르는 영역 최소 44px**(주 버튼 52px, 입력 48px).

## 5. 구성 요소
| 요소 | 모양 | 비고 |
|---|---|---|
| 상단 메뉴 | 흰 바탕 고정, 로고 + 분야별 펼침 메뉴 | 펼침 안 항목은 아이콘·이름·한 줄 설명 카드 2열, 모바일은 햄버거 |
| 맨 위 검색 | 큰 둥근 입력(56px) + 입력 즉시 바로가기 목록 | 상황어 검색(퇴사→퇴직금·실업급여), 방향키·Enter·Esc, 바깥 누르면 닫힘 |
| 많이 찾는 카드 | 아이콘 타일 + 분야·제목·설명 + 분야 색 버튼 | PC 2열, 작은 모바일은 2열 타일(아이콘·제목만) |
| 목록 카드 | 아이콘 \| 분야·제목·설명 \| 꺾쇠 | 카드 전체가 링크, 모바일은 분야별 4개 + "더 보기" |
| 필터 칩 | 둥근 캡슐, 선택 시 분야 색 채움 | `aria-pressed` 사용 |
| 입력 칸 | 라벨 위, 힌트·오류는 칸 바로 아래 | 금액은 "만/억" 미리보기, 빠른 금액 칩 |
| 주 버튼 | 화면 폭 꽉 찬 파란 버튼 | 모바일은 화면 아래 고정 |
| 결과 | **핵심 숫자 하나를 크게** + 적용 기준 + 요약 복사 | 그 아래 보조 숫자 3개 → 상세 표 → 공식·주의 |
| 예전 결과 | 입력이 바뀌면 흐리게 + 노란 "다시 계산" 띠 | 지금 입력과 다른 결과를 믿지 않게 |
| 상세 페이지 틀 | PC: 왼쪽 분야 목록(240px, 현재 항목 채움) + 본문 | 모바일: 위쪽 "계산기 선택" 접기 메뉴 |
| 접기 | 설명·예제·출처는 기본 접힘, 오른쪽 꺾쇠 | details/summary 사용 |
| 안내 상자 | 옅은 바탕 + 얇은 테두리 | 왼쪽 두꺼운 색 띠는 쓰지 않음 |

## 6. 아이콘·로고
- 아이콘: 직접 그린 단순 선 아이콘(24×24, 선 1.8, 둥근 끝) — 분야 색 글자 + 옅은 분야 바탕 타일.
- 로고: 그라데이션 육각형(하늘색→파랑→보라→분홍) + 흰 두 줄. 파비콘·홈 화면 아이콘(180/192/512, 마스크용) 세트.

## 7. 접근성·품질 원칙
- 키보드 포커스 3px 테두리 항상 표시, 본문 바로가기 링크.
- 색만으로 구분하지 않기(필수/선택은 글자 표시).
- 결과·검색 개수는 화면 낭독기에 알림(`role="status"`).
- 다크 모드 색 따로 지정, "움직임 줄이기" 설정 시 애니메이션 끔.
- 가로 스크롤 없음(360px까지 확인).

## 8. 다른 웹에 옮길 때
1. `design-starter.css` 를 불러오고 `:root` 의 `--brand`·분야 색만 그 사이트 색으로 바꾼다.
2. 분야(카테고리)가 없다면 `.cat-1` 하나만 쓰거나 `--c: var(--brand)` 로 통일.
3. 로고·문구·"생활계산서" 이름은 이 사이트 고유 자산이므로 새 사이트 것으로 교체.
4. 글꼴 Pretendard 는 무료 라이선스(OFL)라 그대로 사용 가능.

# UI UX Pro Max 화면 점검 (2026-11-21)

대상: 홈, 월급 일할, 주휴수당, 연봉 실수령액, 양도소득세, 전세보증금 안전 — 390px(모바일)·1280px(PC), 로컬 빌드(운영과 동일 소스)
기준: UI UX Pro Max 스킬 우선순위 표(접근성 → 터치 → 레이아웃 → 타이포·색 → 폼 → 내비게이션) + 스킬 검색 결과(ux 도메인)

## 통과
| 항목 | 결과 |
|---|---|
| 글자 대비 4.5:1 (큰 글자 3:1) | 위반 0건 (6개 페이지 × 2개 너비, 화면에 보이는 모든 글자) |
| 12px 미만 글자 | 0건, 본문 16px · 줄간격 1.6 |
| 입력칸 글자 16px (iOS 자동 확대 방지) | 통과 |
| 키보드 포커스 표시 | 모든 입력·버튼·링크에 3px 포커스 링 |
| 제목 구조 | 페이지마다 H1 1개, 단계 건너뜀 없음 |
| 확대 허용 · 가로 스크롤 | 확대 차단 없음, 가로 넘침 없음 |
| 동작 줄이기(prefers-reduced-motion) | 지원 |
| 오류 표시 | 오류는 해당 칸 바로 아래, aria-invalid·aria-describedby 연결, 첫 오류 칸으로 포커스 이동 |
| 스타일 방향 | 스킬 추천(금융·계산기: 미니멀·스위스 스타일 + 신뢰감 있는 남색·파랑)과 현재 디자인 일치 |

## 수정 필요
| 우선 | 항목 | 내용 | 제안 |
|---|---|---|---|
| 높음 | 포커스된 입력칸이 고정 영역에 가려짐 (WCAG 2.4.11) | 모바일에서 상단 고정 헤더(98px)와 하단 고정 버튼 바(74px) 때문에, Tab·다음 칸 이동이나 오류 칸 자동 포커스 때 입력칸이 헤더 밑으로 완전히 가려지는 경우가 있음 (예: 연봉 실수령액 비과세 칸, 양도소득세 양도가액 칸, 전세 보증금 칸) | `html { scroll-padding-top }`·`scroll-padding-bottom`을 고정 영역 높이만큼 지정 |
| 중간 | 모바일 고정 영역 과다 | 390×800 화면에서 헤더 98px + 하단 바 74px = 화면의 약 21% | 모바일에서는 헤더를 고정하지 않거나 한 줄로 축소 |
| 중간 | 오류 요약 없음 | 오류가 여러 개일 때 칸별 오류만 있고 폼 위 요약이 없음 (스킬 권장: 요약 + 각 칸 링크, 칸별 오류 유지) | 오류 2개 이상이면 폼 위에 요약 상자를 표시하고 각 항목을 해당 칸으로 연결 |
| 낮음 | 터치 영역 44px 미만 | 로고 링크 35px·"← 계산기 목록(홈)" 링크 35px 높이, 월급 일할 달력 날짜 43×44px (WCAG 최소 24px은 통과, 권장 44px 미달) | 해당 링크 최소 높이 44px |

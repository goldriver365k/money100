## 문제없이 확인된 항목 (디자인 품질 검토 9항목)

1. **전체 디자인 일관성**: h1 28px, 카드 모서리 12px, 색 변수가 홈·계산기 두 페이지에서 같음. 차이는 로고 위치(문제 7)뿐.
2. **글자 크기·가독성**: 본문 16px, 카드 설명 16px, 안내 목록 14.4px, 준비 중 안내 13.6px, 개수 문구 14.4px, 푸터 14px. 13px 미만은 배지 3종(문제 3)뿐.
3. **색상 대비**: placeholder(문제 1)를 빼면 위 표의 모든 요소가 라이트·다크 모두 4.5:1 이상.
4. **입력창·버튼 사용성**: 칩 5개 모두 높이 44px(너비 63~121px), 검색창 높이 48px, 이용 가능 카드 링크는 카드 전체(예: 360px에서 328×344, 328×300). 검색창에 `<label for>` 연결. 포커스 테두리는 칩·검색창·카드 링크 모두 3px solid #0b63ce(카드는 offset 2px).
5. **모바일 반응형**: 360·390·768·1440 모두 가로 넘침 0px, 화면 밖으로 나간 요소 0개. 열 수는 360·390에서 1열, 768에서 2열, 1440에서 3열. 대표 카드는 768에서 2칸(736px), 1440에서 2칸(747px). 360·390에서 칩은 두 줄로 줄바꿈되고 잘리지 않음.
6. **카드 간격·정렬**: 세로 간격 16px(반올림 차이로 15~17px), 가로 간격 16~17px로 일정. 같은 줄 카드 높이는 줄마다 같음(1440: 300/236/262/236, 768: 300/236/236/262). 설명 시작 위치 차이는 문제 5.
7. **오류 메시지(검색·칩 동작)**: 칩을 누르면 `aria-pressed`가 하나만 true. 급여·수당 4개, 퇴직·실업 2개, 4대보험·세금 2개, 부동산 2개, 전체 10개. `주휴`→1, `양도세`→1, `주 15 시간`(공백)→1, `zzz`→0개이며 ‘검색 결과가 없습니다…’ 안내 표시. 검색어+칩 조합(`퇴직금`+급여·수당→0, 전체로 바꾸면 1)도 맞음. 개수 문구는 `role="status"`로 갱신됨. 검색어를 지우면 처음 상태로 돌아옴.
8. **접근성·기본 SEO**: h1 1개 → h2 ‘계산기’ → h3 카드 10개 → h2 ‘적용 기준 및 공식 출처’ → h3 3개. 순서가 건너뛰지 않음. 접근성 트리에서 링크 안 h3, `summary` 안 h2 모두 제목으로 노출됨. `lang="ko"`, title ‘급여 계산기 모음 | 정산노트’, description 107자, `robots: noindex, nofollow`(운영 전 상태), 대체 텍스트가 빠진 이미지 0개. 접이식은 처음에 닫혀 있고, 제목줄 오른쪽 빈 곳(x=300)을 눌러도 열리고 닫힘(제목줄 높이 52px).
9. **미구현 표시**: 준비 중 카드 8개 안에 링크·버튼·tabindex 0개. 눌러도 주소가 바뀌지 않음. Tab 순서는 본문 바로가기 → 로고 → 검색창 → 칩 5개 → 이용 가능 카드 2개 → 접이식 제목줄이며 준비 중 카드는 포커스를 받지 않음. 준비 중 카드에는 점선 테두리, 회색 제목, ‘준비 중’ 배지, ‘지금은 계산할 수 없습니다.’ 문구가 있고 CTA 화살표는 없음.

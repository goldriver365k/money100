# 계산기 30종 구축 — 1차 6종 보고 (2026-11-21)

브랜치: `claude/calc30-phase1` (운영 미배포). 백업: `backup/pre-calc30` (직전 디자인 작업 상태).

## 구조
| 구분 | 파일 | 역할 |
|---|---|---|
| 기준 데이터 | `site/assets/js/rules/rules-data.js` | 연도별 요율·세율·출처. 확인 안 된 값은 `null` + 사유 |
| 기준 조회 | `site/assets/js/rules/index.js` | `getRule(연도, 항목)` — 값 없으면 계산 불가 사유 반환 |
| 공통 검증 | `site/assets/js/calc/common.js` | 금액·소수·정수·날짜 검증, 끝수 처리, 결과 형식 |
| 계산 모듈 | `site/assets/js/calc/*.js` | net-salary, severance, loan, hourly, vat, social-insurance |
| 공통 화면 | `site/assets/js/calc-page.js` | 입력 수집·오류 표시·결과 렌더링·초기화 (모든 계산기 공용) |
| 페이지 정의 | `scripts/calculators.js` | 홈 30종 카탈로그 + 6종 페이지(SEO 문구·입력·FAQ·예제·관련 계산기) |
| 생성기 | `scripts/gen-calculators.js` (`npm run gen`) | 페이지 HTML·홈 카드 생성. 예제 숫자는 실제 계산 모듈로 계산 |

새 연도 추가: `YEARS`에 객체 하나 추가. 새 계산기 추가: 계산 모듈 + `PAGES_SPEC` 항목 + `CATALOG`에 slug + `scripts/pages.js` 등록 후 `npm run gen`.

## 0. 요약

1. **특정 주의 근무시간 하나만으로 자동 판정하면 안 된다.** 근로기준법 제18조제3항은 "4주 동안(4주 미만으로 근로하는 경우에는 그 기간)을 평균하여" 1주 소정근로시간을 보도록 정한다. 사례 1(1주차 16시간인데 4주 평균 14시간 59분 → 미적용)과 사례 3(1·3주차 15시간 미만인데 4주 평균 15시간 → 적용)이 단일 주 판정이 틀리는 경우를 보여 준다(3.4절).
2. 판단 기준은 **실제 근로시간이 아니라 소정근로시간**(사전에 정한 근로시간)이다. 소정근로시간을 넘는 추가 근무는 15시간 판단과 주휴수당 산정에 넣지 않는다.
3. 주별 판정은 ① 1주(7일) 근로관계 유지 → ② 판정 자료 완결 → ③ 평균 15시간 → ④ 소정근로일 개근 순서로 하고, 결과는 **지급 대상 / 지급 대상 아님 / 정보 부족** 중 하나다.
4. 예상액은 시행령 별표 2의 **1일 소정근로시간 × 시급**으로 표시한다. 1일 소정근로시간 = 평균 기간의 소정근로시간 합 ÷ 같은 기간 통상근로자의 총 소정근로일수(기본 주 5일).
5. **실제 근로기간이 4주 미만인 경우(그 기간으로 평균, 판정 가능)**와 **자료를 빠뜨린 경우(정보 부족)**는 같은 판정이 아니다. 법의 괄호는 실제로 4주 미만 근로한 경우에만 적용된다(사례 5A·5B).
6. 공식 자료에 명시가 없거나 상담 답변 사이 표현이 다른 7개 쟁점을 8장에 정리했다. 특히 **"어느 4주를 평균하는가"**는 공식 자료에서 확인하지 못했다.

### 3.3 주차별 판정 순서

판정 주마다 아래 순서로 처음 해당하는 단계에서 판정을 확정한다. 결과 행에는 판정, 이유 코드에 해당하는 문구, 판정 주 날짜, 평균 기간 날짜를 표시한다.

| 단계 | 조건 | 판정 | 이유 코드 · 표시 문구 |
|---|---|---|---|
| S1 | 판정 주 7일 중 재직 종료일 이후 날짜가 있음 | 지급 대상 아님 | `END_BEFORE_WEEK` · "M월 D일까지 재직해 이 주의 7일째(M월 D일)까지 근로관계가 이어지지 않았습니다." |
| S2 | 판정 주 소정근로일에 '결근'이 있음 (평균 기간 자료가 불완전해도 확정) | 지급 대상 아님 | `ABSENCE` · "소정근로일인 M월 D일(요일)에 결근해 개근 요건을 충족하지 않습니다." |
| S3 | 평균 기간 중 근무표가 비어 있는 주가 있음 | 정보 부족 | `MISSING_SCHEDULE` · "M월 D일~M월 D일 주의 근무표가 비어 있습니다. 근무가 없었다면 '이 주는 근무 없음'을 선택하세요." |
| S4 | 재직 중이고 입사 후 28일이 안 됐는데 앞으로 정해진 근무표가 없음 | 정보 부족 | `NEED_FUTURE_SCHEDULE` · "4주 평균을 내려면 M월 D일까지 미리 정해진 근무표가 필요합니다." |
| S5 | 평균 1주 소정근로시간 < 900분 | 지급 대상 아님 | `UNDER_15H` · "평균 기간(M/D~M/D)의 1주 평균 소정근로시간이 X시간 Y분으로 15시간 미만입니다." |
| S6 | 판정 주 소정근로일 중 출근 상태 미입력 | 정보 부족 | `MISSING_ATTENDANCE` · "M월 D일(요일)의 출근 여부를 선택하세요." |
| S7 | 판정 주 소정근로일 0일 | 지급 대상 아님 | `NO_WORKDAY` · "이 주에는 미리 정한 근무일이 없습니다." |
| S8 | 소정근로일 전부 휴가·휴일·휴업으로 실제 출근 0일 | 지급 대상 아님 | `NO_ACTUAL_WORK` · "근무일 전부를 휴가·휴업으로 쉬어 이 주에 실제로 일한 날이 없습니다. 취업규칙에서 출근으로 본다면 지급 대상일 수 있습니다." |
| S9 | 위에 해당 없음 | 지급 대상 | `ELIGIBLE` · "평균 X시간 Y분(15시간 이상)이고 소정근로일 N일을 모두 출근했습니다." (휴가·지각 포함 시 "휴가·지각은 결근으로 보지 않습니다." 덧붙임) |

예상액은 S9이고 시급이 입력된 경우에만 계산한다. 시급이 없으면 "시급을 입력하면 예상액을 볼 수 있습니다."를 표시한다.

### 3.4 단일 주 자동 판정 검증

| 판정 방식 | 사례 1 (주별 16:00·14:00·15:00·14:56) | 사례 3 (주별 12:00·18:00·10:30·19:30) | 결론 |
|---|---|---|---|
| 그 주 근무시간만으로 판정 | 1주차·3주차 '지급 대상' | 1주차·3주차 '지급 대상 아님' | 법 문언(L2)과 다른 결과 |
| 4주 평균으로 판정 (L2) | 평균 14:59 → 4개 주 모두 '지급 대상 아님' | 평균 15:00 → 개근한 4개 주 모두 '지급 대상' | **채택** |

따라서 계산기는 판정 주 하나만 입력받아 판정하지 않는다. 다만 입력 편의를 위해 "이전 주와 같게" 복사 버튼을 두고, 매주 같은 근무표도 4개 주 전부를 입력한 상태로 계산한다.

## 4. 입력 설계

| 입력 | 구분 | 형식 · 검증 | 근거 |
|---|---|---|---|
| 재직 시작일 | **필수** | 날짜. 1주차 시작일이 된다 | 쟁점 #2·#5 |
| 재직 상태 | **필수** | '재직 중' 또는 '퇴사함' 중 선택 | 쟁점 #3·#5 |
| 마지막 재직일 | 퇴사함일 때 **필수** | 날짜. 재직 시작일 이상. "퇴사일이 재직 종료 다음 날을 뜻한다면 그 전날을 입력하세요." 안내 | M3, M7 |
| 주별 일정: 날짜별 '미리 정한 근무시간' | **필수**(평균 기간 4개 주 + 판정할 주) | 날짜별 시(0~23) + 분(0~59), 휴게시간 제외. 빈칸과 0을 구분하고, 주 단위 '이 주는 근무 없음' 버튼을 둔다. 하루 8시간 초과 시 "하루 8시간까지만 소정근로시간으로 반영합니다" 안내 | 쟁점 #1·#4 |
| 소정근로일 출근 상태 | 판정할 주는 **필수** | 근무시간이 입력된 날마다: 출근(지각·조퇴 포함) / 결근 / 휴가·휴일·휴업(결근 아님). 미래 날짜는 '예정'으로 두고 판정을 미룸 | 쟁점 #5 |
| 시급 | 선택 | 원 단위 양의 정수(쉼표 허용). 없으면 판정만 표시 | 쟁점 #6 |
| 통상근로자 근무요일 | 선택 (고급 설정) | 기본 월~금. "같은 일을 하는 정규 근무자가 일하는 요일" | L7 2.나, M1, M9 |
| 입력 주 수 | — | 1주차부터 최대 12주(약 3개월)까지 | 쟁점 H |

시간 계산: 입력은 `{시, 분}`, 저장은 `분 = 시×60 + 분`. 평균 비교는 나눗셈 없이 `합 × 7 ≥ 900 × 기간일수`로 하고, 1일 소정근로시간과 예상액은 분수(분자·분모 정수)로 유지하다가 마지막에만 반올림한다(1차 일할계산기와 같은 원칙).

주의 시작 요일: 재직 시작일의 요일로 자동 결정하고 입력 화면과 결과표에 "1주 = 수요일~다음 주 화요일"처럼 명시한다.

## 5. 결과 설계 — 주차별 지급 판정표

| 열 | 내용 | 예 |
|---|---|---|
| 주차 | n주차 | 2주차 |
| 판정 기간 | 판정 주 7일 | 7/13(월)~7/19(일) |
| 평균 기간 | 15시간 판단에 쓴 기간 | 7/6(월)~8/2(일) · 4주 |

| 판정 | 지급 대상 / 지급 대상 아님 / 정보 부족 (색과 글자 모두로 구분) | 지급 대상 |
| 판정 이유 | 3.3절 문구 | 평균 15시간 0분(15시간 이상)이고 소정근로일 3일을 모두 출근했습니다. |
| 예상액 | 지급 대상이고 시급이 있을 때만. 산식 함께 표시 | 30,960원 (3시간 0분 × 10,320원) |

표 위 요약: "지급 대상 N주 · 지급 대상 아님 N주 · 정보 부족 N주", 시급이 있으면 "지급 대상 주의 예상액 합계 N원". 정보 부족이 있으면 요약 바로 아래에 "추가로 입력할 값" 목록(주·날짜 단위)을 둔다.

결과표 아래 고정 문구:

> 본 계산 결과는 단순 모의 계산이며, 법적 효력을 갖는 증빙자료가 아닙니다.

추가 안내(초안): "이 계산기는 미리 정한 근무시간(소정근로시간)과 출근 기록으로 주휴수당 지급 요건을 판정합니다. 실제 지급액은 근로계약서, 취업규칙, 급여명세서를 확인하세요. 월급제, 일 단위 계약(일용직), 감시·단속적 근로 승인 사업장은 이 판정에 맞지 않을 수 있습니다."

## 9. 구현 메모

- 판정 로직 `weekly-holiday.js`는 1차 `proration.js`처럼 순수 함수로 두고 `judgeWeeks({ startDate, endDate|null, schedule: {ISO날짜: 분|null}, attendance: {ISO날짜: 'present'|'absent'|'excused'|null}, emptyWeeks: [n], hourlyWage|null, normalWorkWeekdays: [1..5] })`가 주차별 `{ week, range, averagingRange, avgMinutes(분수), status, reasonCode, reasonText, dailyMinutes(분수), amount|null }`를 반환한다.
- 날짜는 연·월·일 정수로만 비교(1차와 동일, 시간대 영향 없음).
- 단위 테스트에 7장 사례 전부(보조 사례 포함)와 경계(합 3,599/3,600분, 7일째 퇴사/6일째 퇴사, 빈칸 vs 근무 없음)를 넣는다.
- 쟁점 B·D·E는 설정 상수로 분리해 결정 후 한 곳만 바꾸면 되게 한다.
